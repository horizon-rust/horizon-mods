# Show Me Your Skin!

show_me_your_skin: exact 1:1 Rust port of enjarai/show-me-your-skin (Codeberg, MIT (c) 2022 enjarai), read upstream at dd4f63e. Every upstream class is translated code-for-code; Minecraft/Fabric surfaces (mixins, owo-net, CCA components, braid GUI, keybinds) sit behind `seams`, exactly where the Java mod calls into the engine.

Port by sparticle. Upstream: https://codeberg.org/enjarai/show-me-your-skin (MIT).
